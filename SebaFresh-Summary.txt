GOOGLE SHEET — COLUMN NAMES
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Add these exact column headers in Row 1 of your Google Sheet:

name            — Product name (Tomato, Potato, Onion etc.)
category        — Category (Vegetables, Fruits, Leafy, Oils)
price           — Sale price / discounted price
mrp             — Original price (crossed out). Leave blank if no discount.
price_unit      — Unit for pricing (kg, g, L, pcs)
quantity_type   — weight / volume / pcs
default_qty     — Starting quantity shown on the card
default_unit    — Starting unit (g, kg, ml, L, pcs)
step_qty        — How much each +/- press adds (e.g. 250 for grams)
min_qty         — Minimum order quantity
max_qty         — Maximum available stock today (update every morning)
                  Same unit as default_unit.
                  Set to 0 for Out of Stock.
                  Leave blank for unlimited.
available       — yes / no
featured        — yes / no (shows in Latest section)
description     — Short product description
image1          — First image URL
image2          — Second image URL (optional)
image3          — Third image URL (optional)
